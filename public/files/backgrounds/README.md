# Portfolio backgrounds

The Mineral light theme and Slate dark theme use the faceted backgrounds generated on 2026-09-27. Production serves optimized WebP copies: `mineral-facets.webp` (about 22 KB) and `slate-facets.webp` (about 31 KB).

The originals are retained locally as PNGs. The WebP copies keep mobile background downloads small while preserving both approved themes. Theme-specific washes and opaque panels in `styles/themes.css` keep text readable.

Public URLs: `/files/backgrounds/mineral-facets.webp` and `/files/backgrounds/slate-facets.webp`.

## Generation prompts

### Mineral facets

Use case: stylized-concept. Asset type: full-bleed website background, landscape 16:9. Create an original abstract low-poly faceted surface for a software engineer's portfolio. Large irregular triangular planes like folded matte paper or finely carved mineral, restrained sculptural depth, soft daylight from upper left, a sophisticated pale mineral palette of pearl grey, mist blue and subtle sage green. Mostly light and airy, soft shadows, no black areas. Geometric detail is strongest along outer edges, center is calmer and lower contrast for dark website typography. Crisp elegant flat polygon edges, very subtle tonal shading, no glowing effects, no rainbow, no objects, no text, no logo, no watermark, no UI mockup. Edge-to-edge continuous texture; deliver the background image itself.

### Slate facets

Use case: stylized-concept. Asset type: full-bleed website background, landscape 16:9. Create an original abstract low-poly faceted surface for a software and automation engineer's portfolio. Large angular planes with crisp triangular edges, like folded matte paper carved into a shallow sculptural terrain. Medium desaturated blue-grey slate and muted petrol teal, a few softly lit sage planes near upper right and lower left. Clearly brighter than charcoal or black, with visible color and dimensional facets, while the center remains calm medium slate for website content panels. Soft diffused daylight and shallow shadows, refined architectural material, understated precise geometric structure. Avoid black, deep navy, neon, glow, rainbow, objects, text, logos, watermarks or UI. Edge-to-edge continuous texture; deliver the background image itself.
